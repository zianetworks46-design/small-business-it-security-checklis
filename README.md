# small-business-it-security-checklis
Free, plain-English IT and cybersecurity checklist for small businesses: backups, email security, access control, and compliance basics.
## How to use this

1. Go through each section below.
2. Tick off what you already do.
3. Fix the gaps, starting with the highest-risk ones (backups, email, access).

## 1. Backups

- [ ] Data is backed up automatically every day
- [ ] At least one copy is stored offsite or in the cloud
- [ ] A test restore has been done in the last 90 days
- [ ] Old backup versions are kept in case of ransomware

## 2. Email Security

- [ ] Multi-factor authentication (MFA) is on for all email accounts
- [ ] No unknown forwarding rules or filters in any mailbox
- [ ] Staff know how to report suspicious emails
- [ ] Spam and phishing filtering is enabled

> Hijacked accounts often keep working for days because attackers leave hidden forwarding rules. Changing the password alone is not always enough. See the [Email Hijacking Guide](https://www.zianetworks.net/email-hijacking-guide/).

## 3. Access Control

- [ ] Former employees' accounts are disabled
- [ ] Staff only access the files they need
- [ ] Shared passwords are replaced with a password manager
- [ ] Admin accounts are limited and reviewed regularly

## 4. Devices and Updates

- [ ] Operating systems and software update automatically
- [ ] Antivirus / endpoint protection is active on every device
- [ ] Lost or stolen devices can be locked or wiped
- [ ] Firewall is configured and firmware is current

## 5. Staff Awareness

- [ ] Staff had security awareness training this year
- [ ] Payment or bank detail changes are verified by phone
- [ ] There is a clear person to contact for IT problems

## 6. Compliance Basics (HIPAA, PCI-DSS)

- [ ] You know which regulations apply to your business
- [ ] Sensitive data is encrypted
- [ ] Risk assessments and policies are documented
- [ ] Vendors handling sensitive data have signed the required agreements (e.g. BAA for HIPAA)

> This checklist is general information, not legal advice.

## 7. Incident Response

- [ ] There is a written plan for what to do if you are hacked
- [ ] Key contacts (IT provider, insurer, legal) are listed
- [ ] Backups can be restored within an acceptable time

## Scoring

| Ticked | What it means |
|---|---|
| 80%+ | Good shape, keep reviewing quarterly |
| 50-79% | Some gaps, fix the top risks this month |
| Below 50% | Get a second opinion soon |
